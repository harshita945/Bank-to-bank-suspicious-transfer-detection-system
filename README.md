# Bank-to-Bank Suspicious Transfer Detection System

A project for detecting potentially suspicious bank-to-bank transfers.

## Project structure
- `app.py` — Flask application entry point
- `database.py` — database connection and queries
- `detection.py` — suspicious-transfer detection logic
- `templates/` — HTML templates
- `static/css/style.css` — stylesheet
- `static/js/script.js` — frontend JavaScript
- `requirements.txt` — Python dependencies

## Setup
1. Install Python.
2. Create and activate a virtual environment.
3. Install dependencies with `pip install -r requirements.txt`.
4. Configure database credentials locally using environment variables; do not commit passwords.
5. Run `python app.py` once the application code and database are configured.
